# 画像の差し替え / Replacing images

README と Web ドキュメントの画像は、この `docs/images/` フォルダにまとめています。同じ場所・同じファイル名・同じ形式で差し替えると、両方の表示を更新できます。README 本文の編集は不要です。

All README and web-documentation images are stored here. Replace a file at the same path, with the same name and format, to update both views without editing the README.

| フォルダ / Folder | 内容 / Contents |
| --- | --- |
| `ja/` | 日本語UI・日本語早見表 / Japanese UI and quick reference |
| `en/` | 英語UI・英語早見表 / English UI and quick reference |
| `shared/` | 日英共通の操作GIF・画像・動画 / Shared demonstrations and media |

GIF はそのままアニメーション表示します。クイックスタートは元の MP4 と、README 上で再生できる GIF の両方を同梱しています。

GIFs retain their animation. Quick start includes both the original MP4 and an inline GIF preview.

早見表は v1.5.251 のスムーズブラシのショートカットを反映しています。メインUI画像は v1.5.244 のものです。その他の操作画像・GIFは、元のREADMEのURLから取得したものを保持しています。古いUIが含まれる場合は、下の一覧から該当ファイルを差し替えてください。

The quick reference includes the v1.5.251 Smooth brush shortcuts. The main UI screenshots are from v1.5.244. Other screenshots and GIFs were downloaded from the original README URLs and preserved. Use the list below to replace any older UI captures.

リポジトリへ反映するときは、README と `docs/` をフォルダ構成ごとコピーしてください。ファイル名や拡張子を変える場合は、README と対応する `docs/ja/`・`docs/en/` ページの参照も変更します。GitHub Pages のURLやリポジトリ名に依存しない相対パスを使用しています。

Copy the README files and the complete `docs/` folder into the repository. If you change a filename or extension, also update its references in both READMEs and the corresponding language pages. Media paths are relative and do not depend on the repository name or a GitHub Pages URL.
