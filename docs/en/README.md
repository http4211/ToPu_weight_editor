A Blender add-on for reviewing and editing skin weights.
From a **GPU overlay** drawn in the 3D View, it puts numeric editing, cleanup, smoothing, mirroring, copy / transfer, bone picking, bone creation and display helpers into one place.

No external framework or extra Python package is required.

> **This documentation describes version 1.5.187.**
