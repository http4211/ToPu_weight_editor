ToPu_weight_editor（拡張機能名: **ToPu:Weight Editor**）は、Blender 上でスキンウェイトを確認・編集するためのアドオンです。
Softimage 風のウェイト編集をベースに、3D ビュー上へ描画される **GPU オーバーレイ** から、ウェイトの数値編集、正規化、整理、スムーズ、ミラー、コピー&ペースト、転送、骨取得、表示補助までをまとめて操作できます。

外部 UI フレームワークや追加の Python パッケージは使用せず、Blender 内蔵の GPU 描画と Blender ネイティブのエリア / ウィンドウで動作します。

> **バージョン 1.5.112 時点の仕様です。**
> 1.4 系までにあった N パネル（サイドバー）とクイックパイメニューは廃止され、操作は GPU オーバーレイに一本化されました。
> GPU オーバーレイの表示ショートカットも `W` から `Ctrl + W` に変更されています。

## できること

<p align="center">
  <img width="7600" height="5200" alt="Image" src="https://github.com/user-attachments/assets/860738be-4d6e-4588-8930-3e91fd7d8ddc" />
</p>

- 編集モード・ウェイトペイントモードの両方で、GPU オーバーレイからウェイトを確認・編集
- 選択頂点を軽量なセル表示で一覧化し、3D ビューを見ながら数値を直接調整
- セル・スライダー・プリセット・ブラシによる直感的なウェイト編集
- 通常・スムーズ・グラデーション・投げ縄の 4 種類の独自ウェイトブラシ
- 正規化・小数整理・影響整理・閾値整理・違反整理・未使用整理・段階化
- スムーズ化・ミラー実行・レストポーズ適用
- 頂点コピー&貼付・近接転送・オブジェクト間転送・頂点グループ間転送
- 骨取得・骨トランスフォーム編集・ボーンハイライト・表示補助の切り替え
- Blender 標準方式と独自ボクセル拡散方式（Voxel Heat Skinning）による 2 種類の自動ウェイト
- ウェイトスナップショット（blend ファイル内に名前付きで保存・復元）
- ウェイトカラープレビュー
- Blender のエディタータイプとして使える **ToPu Weight Editor 専用エリア** と、3D ビューとは別の **専用ウェイトエディタウィンドウ**
- 複数メッシュの同時編集と、頂点グループ選択の同期
- 日本語 / 英語 UI（Blender の言語設定に自動追従、または個別に固定）

### ミラー・整理での中央 L/R 均等化

デフォルト設定では、選択頂点ミラー・全体ミラーの実行時に、中心軸上の頂点の L/R ウェイトを自動で均等化します。ミラー詳細の `中央頂点L/R補正` を OFF にすると、この均等化だけを省略できます。
`正規化` `小数整理` `閾値整理` `影響整理` `違反整理` では、編集可能な L/R ペアが実行前に等しい場合、その対称性を維持します。意図的に非対称なペアは非対称のままです。小数の丸めと影響数の絞り込みは、等しい L/R ペアを 1 つの対称単位として扱います。

## 動作環境

- **Blender 4.2 LTS 以降**

追加の Python パッケージのインストールは不要です。Blender に同梱されているモジュールだけで動作します。
NumPy は Blender に含まれていれば利用し、無い場合はメインスレッドのスカラー処理へフォールバックします。Voxel Heat の高密度 NumPy 処理は推定作業メモリを 384 MiB に制限し、上限超過またはメモリ確保失敗時は低メモリのスカラー処理へ切り替わります。

一部の古い CPU・GPU 環境では、Blender のグラフィックス API が `Vulkan` に設定されている場合にパフォーマンスが低下することを確認しています。
その場合は、Blender のグラフィックス API を `OpenGL` に変更することで改善する場合があります。

## インストール

### 1. ダウンロード

[**⬇ ToPu Weight Editor をダウンロード（GitHub Releases）**](https://github.com/http4211/ToPu_weight_editor/releases)

リリースページを開き、最新バージョンの `Assets` から配布 ZIP をダウンロードします。

### 2. ZIP をインストール

Blender の `編集 > プリファレンス > アドオン` を開き、`ディスクからインストール` で配布 ZIP を選択します。

### 3. アドオンを有効化

アドオン一覧で `ToPu:Weight Editor` を有効化します。
有効化すると、3D ビューのツールヘッダーに 2 つのアイコンボタンが追加されます。

### ツールヘッダーから起動

3D ビューのツールヘッダーに表示される 2 つのボタンから起動します。

| ボタン | 動作 |
| --- | --- |
| アーマチュアアイコン | 3D ビュー上に GPU オーバーレイを表示 / 非表示 |
| ウィンドウアイコン | 専用ウェイトエディタウィンドウを開く / 閉じる |



ツールヘッダーのボタンは、アドオンプリファレンスの `ツールヘッダーにGPUオーバーレイボタンを表示` で非表示にできます。

### エリアを切り替えて起動

Blender の任意のエリアを、ウェイト編集専用の `ToPu Weight Editor` エリアへ切り替えて起動することもできます。

1. 任意のエリア左上にある **エディタータイプ** の切り替えボタンを開きます。
2. エディター一覧から `ToPu Weight Editor` を選択します。
3. すでに別の場所で HUD が動作している場合は、表示された `こちらをメインにする` を押します。

元のエディターへ戻す場合は、同じエディタータイプの切り替えボタンから 3D ビューなどを選択します。

### ショートカットで起動

デフォルトでは `Ctrl + W` で GPU オーバーレイの表示 / 非表示を切り替えられます。
閉じるときは `Ctrl + W`、または `Esc` を使います。

## GPU オーバーレイ

### 全体レイアウト

<p align="center">
  <img width="589" height="653" alt="image" src="https://github.com/user-attachments/assets/d8064441-2909-41a7-8118-2e52b6f28461" />
</p>

上から順に、次の要素で構成されています。

1. **ヘッダー行** … 移動ハンドル、グリッド表示トグル、ウェイトスナップショット、プリファレンス、UI 倍率、閉じるボタン
2. **骨トランスフォーム行** … 選択列に対応する骨がある場合のみ表示
3. **4 つのセクション** … `編集` / `ウェイトコピー` / `ブラシ` / `整理`
4. **表示補助行** … `モディ` `レスト` `最前面` `オーバーレイ` `骨ハイ` `マテリ`
5. **自動整理の基準値行** … `正規化` `小数点` `閾値` `影響数`
6. **プリセット行** … プリセット値、`▣↖`、`骨取得`、`ロック`、`無視`、`強制表示`
7. **入力行** … 入力モード、スライダー、数値欄、`適用`、`⟳`
8. **ウェイトグリッド** … 列タブと `非表示ワード` を含む

- 上部の `ドラッグで移動` をドラッグすると、GPU オーバーレイの位置を動かせます。
- 四隅からドラッグすると表示サイズを変更できます。
- 表示できる行数・列数は HUD / 専用エリアの実際の描画サイズに追従します。スクロールバーまたはホイールで、表示範囲を移動できます。

### ヘッダー行

| 表示 | 動作 |
| --- | --- |
| `ドラッグで移動` | ドラッグで GPU オーバーレイの位置を移動します。 |
| `グリッド表示` | グリッド表示とリアルタイム更新をまとめて切り替えます。 |
| `▣` | 対象オブジェクトの全ウェイトを名前付きで保存します。 |
| `↶` | 保存済みの一覧から選び、対象オブジェクトの全ウェイトを復元します。 |
| `🗑` | 保存済みの一覧から選び、不要なウェイト保存を削除します。 |
| `⚙` | このアドオンのアドオンプリファレンスを開きます。 |
| `AUTO ×1` | クリックで `自動` → `×1` → `×1.5` → `×2` を順に切り替えます。`Shift + クリック` で `0.50〜4.00` のカスタム倍率を入力できます。 |
| `×` | GPU オーバーレイを閉じます。 |

3D ビュー用と専用エリア / ウィンドウ用の HUD 倍率は別々に保存され、次に開いたときも前回の設定が使われます。`自動` は Blender の UI 倍率と描画領域に合わせて調整されます。

### ウェイトグリッド

**列ヘッダー**

- 列ヘッダーをクリックすると、その列が選択列になります。
- `Shift + 列クリック` で、その頂点グループに値が入っている頂点をまとめて選択します。
- `Ctrl + 列クリック` で、現在選択中の頂点の中から、その列に値が入っている頂点だけを残します。
- 列ヘッダーを右クリックすると、[ウェイト転送メニュー](#列右クリックのウェイト転送)を開けます。

**固 / 頂点 / 合計**

<img width="149" height="30" alt="Image" src="https://github.com/user-attachments/assets/20e5f137-204f-4693-84a6-e9f5455eb703" />

<p align="center">
  <img width="1192" height="762" alt="Image" src="https://github.com/user-attachments/assets/1f944500-6102-4533-915b-c1667d87732d" />
</p>

| ヘッダー | クリック | 修飾キー |
| --- | --- | --- |
| `固` | 対象頂点をウェイトロックします。 | `Alt + クリック` でロック解除 |
| `頂点` | 表示中の行をグリッド選択します。 | `Alt + クリック` で解除 |
| `合計` | **違反のみ表示**を切り替えます。 | `Shift + クリック` でグリッドに表示中の頂点をメッシュ選択 |

- 各行の `固` セルをクリックすると、その頂点のウェイトロックを切り替えます。ドラッグで複数頂点をまとめて ON / OFF できます。
- 各行の `頂点` セルをクリックすると、その頂点行がビュー上でハイライトされ、グリッド上で常に表示状態になります。
- `Shift` / `Ctrl` を押しながらドラッグやクリックで、行選択を追加・解除できます。
- 影響数や合計値に問題がある頂点があると、`合計` ヘッダーが `合計 ⚠` に変わります。違反のみ表示中は `違反のみ` と表示されます。
- 違反のみ表示は、現在のページだけでなく全ページの違反行を対象にします。
- 違反のみ表示中は、`頂点` と `固` のヘッダー操作も表示中の違反頂点だけを対象にします。

**セル**

<p align="center">
  <img width="1184" height="758" alt="Image" src="https://github.com/user-attachments/assets/d40e61e9-ae42-4cf0-b916-46545d88c886" />
</p>

- セルをクリックすると、そのセルの数値を直接入力できます。`Enter` で確定、セルを `右クリック` でキャンセル / セル選択の解除。
- 入力の先頭に `+` `-` `*` `/` を付けると、現在値に対する相対演算になります（例: `*0.5`、`+0.1`）。
- 複数セルを選択している場合は、入力値を選択セルへまとめて適用できます。
- セルをドラッグして範囲選択できます。`Shift + ドラッグ` で選択へ追加、`Ctrl + ドラッグ` で選択から解除。
- 選択セルが残っている場合、スライダー、ホイール、プリセット、数値適用など、すべての値変更系操作で実メッシュ選択より選択セルが優先されます。
- セル選択はページ移動、スクロール、表示行 / 列数や選択列の変更後も保持されます。実際のメッシュ頂点選択範囲が変わると無効になります。
- グリッドの空白部分を右クリックすると、残っているセル選択を解除します。左クリックは 3D ビューへ通らず、グリッドの空白操作として処理されます。

### 表示タブ

<img width="724" height="25" alt="Image" src="https://github.com/user-attachments/assets/d9a3ea5b-4ce8-4942-994f-391fd78fc45b" />

<p align="left">
  <img width="1186" height="764" alt="Image" src="https://github.com/user-attachments/assets/153b50ac-3af7-404e-9795-18da04257bc9" />
</p>

グリッド下部のタブで、表示する列の種類を切り替えます。

- `すべて` : ボーン列と非ボーン頂点グループ列を表示します。
- `変形` : ボーン名と一致する変形用の頂点グループ列だけを表示します。
- `その他` : ボーン名と一致しない非ボーン頂点グループ列だけを表示します。

タブごとのオプション。

- `非ボーン列を無視` :「すべて」タブのオプション。非ボーン頂点グループを自動的に無視状態にして、合計・正規化・整理の対象から外します。
- `作成済み常時` :「その他」タブのオプション。選択頂点に値が入っていなくても、作成済みの非ボーン頂点グループ列を常に表示します。
- `不正規許可` :「その他」タブのオプション。ON のとき、その他列は合計が 1 以上でも違反扱いにせず、正規化 ON でも正規化しません。
- `非表示ワード` : グリッド上のグループ名表示から指定したワードを隠して短く表示します。実際の頂点グループ名は変更されません。

### ロック / 無視 / 強制表示

<img width="156" height="26" alt="Image" src="https://github.com/user-attachments/assets/7d078ee1-5d84-48fb-b533-4b6c889e2c08" />

<p align="left">
  <img width="1192" height="766" alt="Image" src="https://github.com/user-attachments/assets/5d1c7790-e614-45b6-8d47-9243c6fb875a" />
</p>

- `ロック` : 選択列を編集できない状態にします。
- `無視` : 対象列を合計・正規化・整理の対象外として扱います。「その他」タブではその他専用の無視として扱われます。
- `強制表示` : 0 ウェイトの列でもグリッドに強制表示します。
- `Shift + クリック` で選択列以外を対象に作用します。
- `Ctrl + 強制表示` で文字フィルターを開きます。カンマ区切りの複数ワードに部分一致するグループをまとめて強制表示でき、手動で強制表示した列は維持されます。
- `Alt + クリック` で対象の状態をすべて解除します。

### 入力モード / スライダーと数値欄

<img width="431" height="156" alt="Image" src="https://github.com/user-attachments/assets/3ff92ec4-e965-47e9-a535-421889cac398" />

<img width="693" height="37" alt="Image" src="https://github.com/user-attachments/assets/56fd28a7-e82b-4c60-a4ee-034649542502" />

<p align="left">
  <img width="1188" height="756" alt="Image" src="https://github.com/user-attachments/assets/e0c3594f-f8f7-43d0-a298-a64aca7c210e" />
</p>

左端のボタンで入力モードを `ABS` → `ADD` → `ADD%` の順に切り替えます。

- `Abs` : 入力した値で置き換えます。
- `Add` : 現在値に加算します。負の値で減算できます。
- `Add%` : 現在値に対して割合で加算します。

操作方法。

- スライダーをドラッグすると、通常は対象へ値をリアルタイムに適用します。対象が **1 万頂点以上**の場合は、ドラッグ中は表示とハンドルだけを更新し、スライダーを離して確定した時点でウェイトを適用します。
- 数値欄をクリックすると、キーボードから直接入力できます。
- 数値欄の上でホイールすると、値を少しずつ変更できます。
- `適用` ボタンで、数値欄の値を選択頂点の現在列に適用します。
- `⟳` ボタンで、現在の選択頂点とウェイト値でグリッドを手動更新します。特殊な選択コマンドの後などに使います。
- `Ctrl + ホイール` で選択頂点に選択列のウェイトを加算 / 減算できます（スライダーのモードには影響されません）。
- `Ctrl + Shift + ホイール` でより細かい単位で加算 / 減算できます。
- ホイールによる増減量は、アドオンプリファレンスから変更できます。

## 骨取得 / 最大ウェイト列を追従

## ブラシ

<p align="left">
  <img width="192" height="111" alt="Image" src="https://github.com/user-attachments/assets/2e57f831-8509-4954-81cc-e75aed5e66c3" />
</p>

GPU オーバーレイから、ビューポート上で使う TPWE 独自のウェイトブラシを開始できます。
ブラシは編集モードとウェイトペイントモードの両方で使用できます。
ブラシ中でも骨取得や骨トランスフォームを併用できるため、ウェイト作業を素早く進められます。

ブラシ中は `F` でサイズ変更、`Tab` / `Q` / `Esc` で元のツールへ戻れます。
ツールヘッダーでは、サイズ、選択マスク、通常量、スムーズの強さ、グラデ値、投げ縄値などを調整できます。

### 通常ブラシ

<img width="436" height="27" alt="Image" src="https://github.com/user-attachments/assets/714c3d89-c99d-47ab-b348-2b36a4712cb2" />

<p align="left">
  <img width="898" height="764" alt="Image" src="https://github.com/user-attachments/assets/51d508d6-5c53-45cc-88a1-5d793de41f40" />
</p>

`通常` は、選択列のウェイトをブラシで加算 / 減算する基本ブラシです。

- 左ドラッグで選択列へ加算します。
- `Ctrl + 左ドラッグ` で減算します。
- `Shift + 左ドラッグ` で一時的にスムーズ処理になります。
- `Ctrl + Shift + 左ドラッグ` で、周辺の影響を広げます。
- `通常量` で 1 ストロークあたりの変化量を調整できます。
- `一定塗` : 1 回のドラッグ中に同じ頂点へ何度も当たっても、重ね塗りされすぎないように塗ります。狙った量だけ安定して足したいときに向いています。
- `重ね塗` : ブラシが当たるたびに現在値へ `通常量` を加算 / 減算します。何度もなぞって徐々に強くしたいときに向いています。

### スムーズブラシ

<img width="719" height="31" alt="image" src="https://github.com/user-attachments/assets/753ab833-efb9-4ae2-b11c-810763683587" />

<p align="left">
  <img width="1268" height="762" alt="Image" src="https://github.com/user-attachments/assets/fe1cc575-10d5-49c8-884a-3b3351182f5a" />
</p>

`スムーズ` は、選択列のウェイトを周囲の頂点になじませるブラシです。

- 左ドラッグした周辺のウェイトをなめらかにします。
- `Shift + 左ドラッグ` で、指先でなぞるようにウェイトをスミアします。
- `Ctrl + 左ドラッグ` で、周辺の影響を広げます。`Ctrl` が優先されます。
- `強さ` でどれだけ周囲へ寄せるかを調整できます。
- `回数` でスムーズ処理の反復回数を調整できます。
- 無視列を選択している場合は、その無視列だけを処理します。
- 塗り跡が硬い部分、段差が出た部分、ミラー後の境界を整える用途に向いています。

### グラデーションブラシ

<img width="640" height="24" alt="Image" src="https://github.com/user-attachments/assets/a15031da-149f-49f5-84be-c73567c54603" />

<p align="left">
  <img width="1234" height="756" alt="Image" src="https://github.com/user-attachments/assets/df2d5bc8-1fbb-4c8d-90ff-31e5a5a0b02a" />
</p>

`グラデ` は、ドラッグ方向に沿ってウェイトのグラデーションを作るブラシです。

- ドラッグ開始位置から終了位置に向かって、選択列のウェイトを変化させます。
- `グラデ値` で最大ウェイト値を調整できます。減衰カーブに沿って、この値から 0 へ変化します。
- `Ctrl` を押しながら実行すると減算方向、`Shift` を押しながら実行すると加算方向として使えます。
- `リニア` : ドラッグ方向へ 1 から 0 の直線的なグラデーションを作ります。
- `放射` : ドラッグ開始点を中心に、外側へ向かって弱くなる放射状のグラデーションを作ります。
- `線放射` : ドラッグした線を基準に、線方向と反対方向へ広がるグラデーションを作ります。
- `減衰` では値の落ち方を切り替えられます。`リニア` は均等、`スムーズ` は自然な S 字、`球状` は柔らかめ、`ルート` は開始側を広め、`シャープ` は開始側から強めに落ちます。
- `カスタム` 減衰では `カスタム指数` で `0.1〜8` の間で落ち方を調整できます。`1` がリニア、`2` 以上で急減衰、`1` 未満で緩やかになります。

### 投げ縄ブラシ

<img width="384" height="27" alt="Image" src="https://github.com/user-attachments/assets/4756f60d-3580-463b-bf3a-96aeaafadef0" />

<p align="left">
  <img width="1154" height="796" alt="Image" src="https://github.com/user-attachments/assets/9c2046e0-adc7-49cd-98e2-7e854064ee5f" />
</p>

`投げ縄` は、囲んだ範囲を指定値で塗るブラシです。

- 左ドラッグで範囲を囲むと、その内側へ `投げ縄値` を適用します。
- `Ctrl` を押しながら実行すると減算方向、`Shift` を押しながら実行すると加算方向として使えます。
- ブラシサイズは、範囲の境界をなじませる幅として使われます。
- 広い範囲を一気に 0、0.5、1.0 などへそろえたい場面に向いています。

### 選択マスク

<p align="left">
  <img width="1208" height="772" alt="Image" src="https://github.com/user-attachments/assets/4c9e47f7-afae-4fa9-9dfe-8d135c61ee2d" />
</p>

`マスク` を ON にすると、ブラシの影響先を現在選択中の頂点だけに制限します。

- 近い別パーツや裏側の頂点へ意図せず塗るのを防ぎやすくなります。
- 先に編集したい頂点だけを選択してから ON にすると、ブラシ作業の範囲を安定させられます。
- 通常、スムーズ、グラデ、投げ縄の各ブラシで共通して使えます。

## 編集

<p align="left">

`編集` セクションには、見出し行の `x-` / `x+` と、`スムーズ化` / `ミラー実行` / `レストポーズ適用` の 3 ボタンがあります。

### X 方向の頂点選択

<img width="53" height="25" alt="Image" src="https://github.com/user-attachments/assets/b50216db-62f4-4d14-b880-35172f970311" />

<p align="left">

アーマチュア原点を基準に `x-` 側または `x+` 側の頂点を選択できます。
アーマチュアがない場合は、各オブジェクト原点を基準にします。

- 通常のクリックでは中心線上の頂点は選択しません。
- `Shift + クリック` で中心線上の頂点を選択します。

### スムーズ化

<img width="296" height="163" alt="Image" src="https://github.com/user-attachments/assets/9b1fc7b0-366f-4646-b56b-dacad2702608" />

<p align="left">
  <img width="1236" height="764" alt="Image" src="https://github.com/user-attachments/assets/ba09f7df-ebff-4b3c-886e-9c563eec4936" />
</p>

選択頂点のウェイトを周囲へなじませます。

- 通常クリック : 選択頂点をスムーズ化します。
- `Shift + クリック` : 選択列のウェイト範囲全体と、その外側 1 リングを自動スムーズします。詳細設定で「選択頂点のみ」に制限できます。
- `Ctrl + クリック` : 未選択の周囲を基準に異常なウェイトを修正します。`Ctrl` が優先されます。
- 右隣の `…` から詳細設定を開けます。対象範囲、稼働方式、回数、実行後の整理方法を調整できます。
- 稼働方式は `高速` / `表面` / `ボリューム` の 3 つから選択できます。

### ミラー実行

<img width="484" height="459" alt="Image" src="https://github.com/user-attachments/assets/b6c7b993-1e28-4ab3-925b-db2b697cd7b8" />

<img width="340" height="232" alt="Image" src="https://github.com/user-attachments/assets/b0c1e84f-6dbd-4a73-9186-fa0eee9e6912" />

<p align="left">
  <img width="1354" height="762" alt="Image" src="https://github.com/user-attachments/assets/f45e4116-7cf0-4867-9eca-9b5b7fdc8ead" />
</p>

選択頂点の反転位置を参照し、反対側の頂点からウェイトを持ってきます。
`_L` / `_R` などの左右名も入れ替えて適用でき、中央頂点の L/R ウェイトも均等化されます。

- `Ctrl + クリック` : 方向指定・全体ミラーの設定を開きます。
- 右隣の `…` から詳細設定を開けます。ミラー方向、基準空間、検索距離、中央許容、左右ワードセットを調整できます。
- 方向が `自動` の場合、編集モードでは実際のメッシュ選択側から方向を判断します。両側選択または判定不能時は、アクティブ頂点や選択数では決めず、ミラー詳細の方向設定を使用します。
- ミラー詳細の方向自体も `自動` の場合、両側選択では従来の頂点ごとの自動方向を使用します。
- 左右非対称の形状では、反転位置をコピー元サーフェスへ投影し、近傍三角形のウェイトを補間する適応マッチングを使用します。完全対称の位置は従来の高速な最近傍頂点経路を使い、適応処理は詳細設定で無効にできます。
- `中央頂点L/R補正` はデフォルト ON です。OFF にすると中央頂点の平均化だけを省略できます。
- 左右ワードセットはアドオンプリファレンスからでも設定できます。
- 全体ミラーには「選択頂点のみ」オプションがあります。

### レストポーズ適用

<p align="left">
  <img width="1302" height="768" alt="Image" src="https://github.com/user-attachments/assets/9f61975e-ab08-4fa3-a47d-47aefd04bfdf" />
</p>

`レストポーズ適用` は、現在の見た目のポーズを新しいレストポーズとして適用する機能です。

- ボーン配置を調整した後、その状態を新しいレスト姿勢にしたい場合に使用します。
- アクションとシェイプキーのリターゲットに対応しています。
- アーマチュアのレストデータ、メッシュとシェイプキーの座標、アクション、NLA から参照されるアニメーションを変更する可能性があります。
- **実行前に必ずバックアップを取ってください。** 確認ダイアログの内容も確認してから実行してください。

## ウェイトコピー

<img width="165" height="108" alt="Image" src="https://github.com/user-attachments/assets/ef71a5b2-b587-4898-bbdc-6eb6a670ac43" />

<p align="left">
  <img width="1042" height="770" alt="Image" src="https://github.com/user-attachments/assets/b8453e66-c226-46db-b887-b2e01a3a3042" />
</p>

| ボタン | 動作 |
| --- | --- |
| `頂点コピー` | 現在アクティブに選択している 1 つの頂点ウェイトをコピーします。 |
| `頂点貼付` | コピーした頂点ウェイトを選択頂点へ貼り付けます。 |
| `近接コピー` | 選択頂点の位置とウェイトを保存し、近接貼付のコピー元にします。 |
| `近接貼付` | 近接コピーで保存した頂点群から、選択頂点に最も近いウェイトを貼り付けます。 |
| `自動ウェイト` | 選択メッシュをアーマチュアへ紐づけ、自動ウェイトを割り当てます。 |
| `オブジェクト転送` | 保存設定を使って、アクティブメッシュのウェイトを他の選択メッシュへ転送します。 |

`自動ウェイト` と `オブジェクト転送` の右隣の `…` から、それぞれの詳細設定を開けます。

### S / T ボタン（列の転送）

セクション見出しの右側にある `S` と `T` は、現在の選択列に対する転送ショートカットです。

- `S` : 現在の選択列をウェイト転送元として登録します。登録中は色が変わります。
- `T` : 登録済みの転送元から、現在の選択列へ転送します。
- `Shift + T` : 転送元と現在の選択列をあらかじめ入力した状態で、`複数ウェイト転送` ダイアログを開きます。

### オブジェクト転送

選択順の最後に選択したアクティブオブジェクトから、他の選択オブジェクトへウェイトを転送します。
面ベースで転送するため、通常の転送に比べてローポリでも比較的きれいに転送されます（その分、処理は重めです）。

詳細設定では、方式・補間・Robust 補完・仕上げ設定を調整できます。
`Robust Weight Inpainting` を使うと、一致しなかった領域を補完しながら転送できます。
`衣装裏面モード` を使うと、コピー元の法線と距離を利用して内側シェルの候補を優先し、届かない領域をトポロジー補完します。`近接貼付` も保存済みのオブジェクト転送設定にある補間、距離、衣装裏面モードを使用します。

転送先に Armature モディファイアが無い場合は自動で追加できます（デフォルト ON、オブジェクトウェイトコピー設定で無効化できます）。

### 自動ウェイト

<img width="552" height="381" alt="Image" src="https://github.com/user-attachments/assets/6f5d9511-81a5-4bed-84a8-b8a937823c8e" />

<img width="438" height="332" alt="image" src="https://github.com/user-attachments/assets/0e5ccde7-2528-4d22-809d-38c535ad8d5b" />


<p align="left">
  <img width="1406" height="958" alt="Image" src="https://github.com/user-attachments/assets/ecde6c2a-a6d8-4069-81aa-55582c799c53" />
</p>

`自動ウェイト` は、選択メッシュをアーマチュアへ紐づけ、自動ウェイトを割り当てます。
親子関係を維持しながら実行でき、リンクオブジェクトがある場合は自動でローカル化できます。
選択頂点の部位だけを部分的に自動ウェイトでウェイト付けすることも可能です。

詳細設定では、Blender 公式の自動ウェイトと、独自のボクセル拡散方式（Voxel Heat Skinning）を切り替えられます。

**Voxel Heat Skinning の主な設定**

| 項目 | 内容 |
| --- | --- |
| `Voxel Resolution` | 最長辺のボクセル数。品質 / 速度 / メモリを支配します。 |
| `Diffuse Loops` | 総拡散パス数は 解像度 × Loops。大きいほど滑らかですが重くなります。 |
| `Diffuse Falloff` | 大きいほど遠方ボーンの寄与が急減し、局所的で締まったウェイトになります。 |
| `スムーズ回数` | 自動ウェイト後のスムーズ回数。大きいほど広くなじみます。 |
| `Sample Rays` | ソリッド化に使うレイサンプル数。多いほど非防水メッシュに強くなります。 |
| `Detect Solidify` | 薄い衣装などを固体化します。ON の場合は全ボーンがキャラ体積内にある必要があります。 |
| `Use Half CPU Cores` | CPU 使用量を控えめにする互換設定です。 |

非常に重い処理ですが、メッシュの表裏に関係なく空間をボクセル化してウェイト付けを行うため、複雑なモデルでもきれいにウェイトが付きやすいです。

**指定ボーンのみを使用**

`指定ボーンのみを使用` を ON にすると、保存したボーンリストだけを対象に自動ウェイトを計算します。

- Blender 標準の自動ウェイトと Voxel Heat Skinning の両方に適用され、オブジェクトモード / 編集モードのどちらでも動作します。
- `選択ボーンを取得` で、編集モード・ポーズモード・オブジェクトモードのボーン選択を取り込めます。
- `すべて` / `なし` ボタンとボーンチェックリストで調整できます。
- 明示的に選択したボーンは、変形ボーンフラグや除外ワードのフィルタより優先されます。

## ウェイトスナップショット

ヘッダー行の `▣` `↶` `🗑` で、ウェイトの一時保存と復元ができます。

- `▣` : 現在の対象オブジェクトの全ウェイトを、名前を付けて保存します。
- `↶` : 保存済みの一覧から選び、対象オブジェクトの全ウェイトを復元します。
- `🗑` : 保存済みの一覧から選び、不要なウェイト保存を削除します。個別削除と一括削除に対応しています。

スナップショットは圧縮されて blend ファイル内のテキストデータブロックに保存されます。
大きなスナップショットは `.blend` のファイルサイズを増やす点に注意してください。
復元時は、保存時と頂点数が一致している必要があります。

## ウェイトカラープレビュー

表示補助行の `マテリ` で、ウェイトをカラー表示するプレビューを切り替えます。
横の `…` から、色相 / 彩度 / 輝度と、マテリアル置換のオン / オフを設定できます。

- プレビューは、このアドオン専用の一意な名前のカラー属性を作成します。同名のユーザー属性を上書き・削除することはありません。
- `マテリアル置換` はデフォルト OFF です。明示的に有効にした場合のみマテリアルスロットを一時的に置き換え、プレビュー解除時にスロット順、DATA / OBJECT リンク、オブジェクト単位のオーバーライド、アクティブスロット、面ごとのマテリアル割り当てを復元します。
- 複数オブジェクトで共有されているメッシュデータでは、マテリアル置換をスキップしてビューポートのカラー表示を使うため、他のオブジェクトは変更されません。

> `マテリ` 表示は動作が重くなるため、常用は推奨していません。

## 専用エリア / 専用ウェイトエディタウィンドウ

Blender の通常のエディタータイプ選択から `ToPu Weight Editor` を選ぶと、任意のエリアをウェイト編集専用エリアとして使えます。このエリアはスクリーン / ワークスペースとともに `.blend` に保存され、ファイルを開いたときに HUD 表示が復元されます。

- GPU HUD の操作内容は 3D ビュー版と共通です。`表示整理` を使うとヘッダー、ツールバー、サイドバーなどのエディター装飾をまとめて隠し、もう一度押すと以前のレイアウトへ戻せます。
- 同時に操作できる HUD は 1 つです。別の `ToPu Weight Editor` エリアには `こちらをメインにする` が表示され、現在のメインエリアを切り替えられます。HUD が無い場合は `ToPu Weight Editorを開く` から開始できます。
- ツールヘッダーのウィンドウアイコンからは、同じ専用エリアを別の Blender ウィンドウとして開く / 閉じることもできます。
- ウィンドウのサイズと配置は Blender と OS が管理します。GPU UI の大きさは HUD 倍率ボタンで個別に調整できます。
- ビューポート表示の切り替え（`モディ` `レスト` `最前面` `オーバーレイ` など）は、専用ウィンドウを開いた 3D ビューに対して働きます。
- 専用ウィンドウでは、ヘッダーの `×` でウィンドウを閉じます。

## blend ファイルへの変更について

このアドオンはネットワークにアクセスせず、外部プログラムの実行や Python パッケージのインストールも行いません。
外部ファイルの読み書きは、ユーザーが明示的に `カラープリセットのインポート` / `エクスポート` を選んだときだけ行われます。

一部の機能は、意図的に現在の blend ファイルを変更します。

- **ToPu Weight Editor 専用エリア / ウィンドウ** は、専用ウィンドウの識別情報とエリアタイプを Blender の Screen / Workspace に保存します。OS ウィンドウの位置や実行時ポインターは保存しません。
- **ウェイトスナップショット** は、圧縮して Blender のテキストデータブロックに保存されます。大きなスナップショットは `.blend` のサイズを増やします。
- **骨トランスフォームの取り消し用データ** も blend ファイル内にテキストデータブロックとして作成され、不要になったアンカーは自動で削除されます。
- **ウェイトカラープレビュー** は、このアドオン専用の一意な名前のカラー属性を作成します。`マテリアル置換` を有効にした場合のみ、マテリアルスロットを一時的に置き換えます。
- **レストポーズ適用** は、アーマチュアのレストデータ、メッシュとシェイプキーの座標、アクション、NLA から参照されるアニメーションを変更する可能性があります。実行前にバックアップを取ってください。
- **自動ウェイト** は計算中に一時的なメッシュ / オブジェクトデータブロックを作成し、処理終了時に削除します。
- **オブジェクト転送** は、Armature モディファイアを持たない転送先に対して、それを追加できます（デフォルト ON）。

不具合の報告や再現用ファイルは [Issue トラッカー](https://github.com/http4211/ToPu_weight_editor/issues) へお願いします。
